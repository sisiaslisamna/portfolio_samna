# Portofolio Muhammad Hisham

Website portofolio pribadi milik **Muhammad Hisham**, UI/UX Designer & Frontend Developer. Dibangun dengan HTML, CSS, dan JavaScript murni tanpa framework, sehingga bisa langsung di-hosting di GitHub Pages.

🔗 **Demo:** https://sisiaslisamna.github.io/portfolio_samna/

## Fitur

- **Halaman Home**: perkenalan singkat dan kartu identitas bertali yang bisa ditarik dan digerakkan, dengan simulasi fisika tali berbasis canvas.
- **Halaman CV**: tentang saya, hobi, kontak, riwayat pendidikan, dan keahlian, serta tombol untuk mengunduh CV dalam format PDF.
- **Responsif**: tampilan menyesuaikan layar desktop, tablet, dan ponsel.

## Teknologi

- HTML5
- CSS3 (CSS variables, Grid, Flexbox)
- JavaScript (Canvas API, Pointer Events)
- [Bootstrap Icons](https://icons.getbootstrap.com/) dan [Google Fonts](https://fonts.google.com/) (Bebas Neue, DM Sans) via CDN

## Menjalankan Secara Lokal

Tidak perlu instalasi apa pun. Pilih salah satu cara berikut:

1. Buka file `index.html` langsung di browser, atau
2. Gunakan ekstensi **Live Server** di VS Code (klik kanan `index.html` → *Open with Live Server*).

## Deploy ke GitHub Pages

1. Upload seluruh isi proyek ke repository GitHub (pastikan `index.html` berada di root).
2. Buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu 1–2 menit, situs akan aktif di `https://sisiaslisamna.github.io/portfolio_samna/`.
